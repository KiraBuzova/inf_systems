# Прототип: Use-case 1 «Створення заявки»
Сервіс виклику побутових майстрів · мобільний застосунок (екран 390 × 844)

## Екрани (за таблицею з practice_3)
| № | Екран | Що спробувати |
|---|-------|----------------|
| 1 | Головна клієнта | банер із кнопкою «Створити заявку», переваги сервісу, стрічка категорій, «Часті замовлення» (одразу з обраною роботою), промокод MASTER10, блок «Як це працює» |
| 2 | Крок 1/4 · Категорія | список з іконками, «Сантехніка» → ціни |
| 3 | Крок 2/4 · Ціни | вибір роботи, діапазон цін; «Далі» неактивна, доки роботу не обрано |
| 4 | Крок 3/4 · Опис і фото | стани поля: порожнє / фокус / заповнене / помилка (4а); «Додати фото» → панель «Камера / Галерея» (Камера додає демо-фото, Галерея — відкриває вибір вашого файлу); фото необов’язкові (4б) |
| 5 | Крок 4/4 · Адреса | вулиця, квартира, випадаючий список усіх 10 районів Києва; міні-карта; тап по карті відкриває повноекранну карту; «Поза межами Києва» → поза зоною (4в) |
| 5а | Карта (повноекранна) | тап по району ставить мітку; перетягування, кнопки +/− та колесо миші для зуму; чипси районів угорі; кнопка геолокації; тап поза містом — «поза зоною», підтвердити не можна |
| 6 | Помилка форми | порожня адреса → поле червоне «Вкажіть адресу»; тап по полю знімає помилку |
| 7 | Відправлення | гіфка-лоадер, 1,5 с → екран 8 (розчинення) |
| 8 | Заявку створено | «Заявка №1024 створена», статус «Нова» |
| 9 | Мої заявки | картка зі статусом «Нова»; «Скасувати» → модальне вікно → статус «Скасована» |

Категорії (8): сантехніка, електрика, ремонт техніки, дрібні роботи, клінінг, оздоблювальні роботи, вікна та двері, кондиціонери й опалення.

Додатково (з опціональних пунктів): підказка-приклад у полі опису, карта районів Києва на кроці адреси,
сповіщення «1 майстер прийняв вашу заявку» через 4 секунди на екрані «Мої заявки» (зв’язок з use-case 2).
